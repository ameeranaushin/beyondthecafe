# Beyond the Date

Next.js 16, React 19, TypeScript, App Router.

## Run

npm install
npm run dev

Open http://localhost:3000.

## Production

npm run build

Static output is written to out/.

The homepage uses the supplied café images and recreates the supplied video reference. Includes responsive layouts, category filters, anchored navigation, accessible FAQ disclosures, and client-side newsletter validation. Newsletter submission currently shows a local confirmation; connect an email service before collecting subscribers.

Includes Tailwind CSS, Motion, scroll reveals, and transparent animated illustrations with reduced-motion fallbacks. Google Fonts loads Barlow Condensed, DM Sans, and Playfair Display. Desktop, tablet, and mobile layouts have been checked in Chrome.

The project is located at C:/websites/cafe-website. Run the commands above from this folder.
